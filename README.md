# 募資練習平台

給新同事練習「群眾募資」整套作業的平台：**前台（贊助者）**、**提案者後台**、**平台管理後台（admin）** 三個角色都有，金流全部是模擬的，不會真的扣款。

流程、欄位、規則參考台灣主流群眾募資平台的公開資訊（提案說明、常見問答、提案者後台的欄位），練熟了到真的平台操作是同一套。
這不是任何平台的官方系統，也沒有使用任何平台的商標、名稱或畫面。

---

## 怎麼開

不用裝任何套件，只要 [Node.js](https://nodejs.org/) 20 以上。

- **Windows**：雙擊 `啟動練習平台.bat`，會自動打開 http://localhost:3000
- **其他**：`node server.js`

要讓同一個網路的同事一起用：`HOST=0.0.0.0 node server.js`，同事用 `http://你的電腦IP:3000` 連。

| 環境變數 | 預設 | 說明 |
|---|---|---|
| `PORT` | 3000 | 埠號 |
| `HOST` | 127.0.0.1 | 只有這台電腦連得到；改 0.0.0.0 才開放給區網 |
| `DATA_DIR` | ./data | 練習資料放哪（不會上傳到 repo） |
| `SECURE_COOKIE` | 不設 | 架在 https 後面時設 1 |

## 練習帳號（密碼都是 `Demo1234`）

| 帳號 | 角色 | 練什麼 |
|---|---|---|
| admin@demo.local | 平台管理員 | 審核、撥款、會員、平台設定、模擬時鐘、重置 |
| pm@demo.local | 專案經理 | 審核提案、處理退款、檢舉 |
| creator@demo.local | 提案人 | 管理 6 個練習計畫＋4 個嘖嘖移植計畫 |
| backer1～6@demo.local | 贊助人 | 逛計畫、贊助、退款、留言 |

> 這些是練習用的帳號，只在你自己電腦上的 `data/` 裡。不要拿來放真實資料。

## 範例計畫：我們在嘖嘖上的 4 個真實計畫

前台直接搬了我們目前在嘖嘖上的計畫（標題、簡介、文案、圖片、GIF、Vimeo 影片、回饋方案、回饋調查、常見問答、風險、退換貨）：

| 網址 | 計畫 | 類型 |
|---|---|---|
| `/p/moga` | 茅港尾天后宮・光明燈牆 | 群眾集資（首頁主打） |
| `/p/sihu` | 四湖參天宮・光明燈柱 | 群眾集資（首頁主打） |
| `/p/hsu` | 許厝福興宮・廟體修復 | 訂閱式 |
| `/p/pray` | 八間廟・把你的願望放到神明面前 | 訂閱式 |

- 這 4 個計畫都掛在 `creator@demo.local` 底下，新同事可以直接用提案者後台練習改它們。
- **贊助人和訂單是虛構的**（`fan1～fanN@demo.local`，沒有密碼、登入不了），只是讓人數、累計金額、各回饋已認領數跟嘖嘖公開頁面一樣；沒有任何真實贊助人的資料。
- 圖片用的是嘖嘖的公開圖片網址，要有網路才看得到。
- 內容放在 `lib/zeczec_projects.json`。嘖嘖上的計畫改了想重新搬：用 Chrome 重新匯出 `zeczec_export.json`，再跑 `node tools/convert_zeczec.mjs 匯出檔路徑`，然後到平台後台按「重置練習資料」。
- 內容是我們在嘖嘖上已公開的文案和照片；贊助人資料一律不放進 repo。

## 功能

### 前台（贊助者）
首頁（主打、群眾集資／預購式／訂閱式、編輯精選、計畫更新、近期成功）、探索（類型、分類、狀態、排序、搜尋、分頁）、計畫頁（專案內容、計畫更新、留言、常見問答、贊助人、追蹤、分享、聯繫提案人、檢舉、隱藏選項密碼、18 禁提示、推薦連結 `?r=`）、
結帳（數量、加購、加碼、折扣碼、運費依國家、宅配／超商取貨、回饋調查、備註、信用卡分期、ATM 虛擬帳號、AFTEE、電子發票）、模擬付款、
我的贊助紀錄（付款、修改收件資料、取消、退款申請、取消訂閱）、追蹤計畫、提案紀錄、個人頁面、帳號設定、團隊設定、站內訊息、我的信箱（模擬寄信）。

### 提案者後台（16 頁，順序跟主流平台提案者後台一樣）
控制中心（審核五階段、集資統計、最近贊助、最近留言）、修改計畫（封面、標題、簡介、內容編輯器、目標、時程、類型、年齡限制、分類、發源地、網址、影片、客服、風險、退換貨、AFTEE 宣告、GA、Pixel、Google 商品分類、發票、BSMI、NCC、回饋排序）、
常見問答、計畫回饋（價格、預定售價、限量、加購、ATM、分期、折扣碼、**圖片可以放多張，也可以放 GIF 或影片**、SEO、選項內容、預計出貨、備註、隱藏密碼、回饋調查、25 個國家運費、超商取貨、給贊助人的話）、
自訂回饋順序、折扣碼、計畫推薦連結（看各管道訂單數與金額）、EDM 再行銷（未結帳提醒信、預覽、自動寄送）、計畫更新（草稿／發布、公開／贊助人限定／指定回饋、寄信通知）、
數據分析（募得金額成長、每日訂單、選項分布、付款方式、推薦、折扣碼、贊助人過去贊助數）、贊助名單下載（CSV、出貨列表、標記出貨）、訂單總覽、退款申請總覽、留言管理、商業檔案設定、金流帳號申請。
團隊角色：管理者、編輯、客服、檢視（客服看得到訂單、看不到銀行帳號）。

### 平台管理後台
總覽、提案審核（五階段依序：商業檔案與金流帳號初審 → 方案與回饋 → 合約簽署與上傳 → 第三方金流單位審核 → 準備上線；退回要寫原因）、
計畫管理（首頁主打、編輯精選、調整時間、指派專案經理、下架／恢復、解鎖時間）、訂單管理（標記已付款、取消、強制退款）、退款處理、檢舉處理、留言管理、首頁公告、
會員管理（權限、停權、重設密碼）、撥款結算（金流費＋平台費試算、應撥日、標記撥款）、平台設定（手續費、上限、天數、全有全無、分類）、寄信紀錄、操作紀錄、**模擬時鐘**（快轉看募資結束、ATM 逾期、訂閱扣款、撥款到期）、重置練習資料。

### 規則（預設值，都可以在平台設定改）
- 手續費：成功才收，平台 5.5％＋金流 2.5％
- 一次性計畫 1 天～5 個月；訂閱式沒有天期
- 自然人任意連續 30 天 100 萬；法人第一階段 1,500 萬
- 群眾集資、預購式沒達標全部退款（ATM 扣轉帳手續費）
- 撥款：一次性專案完結後 28 個工作日內；訂閱專案次月 15 日
- ATM：訂單成立隔天 23:59:59 前付款，逾期取消
- 方案與回饋通過審核後，網址、目標、類型、時間鎖住
- 模擬信用卡：卡號末四碼 `0002` 會被拒絕，其他都成功

## 資安
- 不用任何外部套件；所有輸入在伺服器清洗、限長度；所有權限在伺服器判斷
- 密碼 scrypt 加鹽雜湊；登入 session 只存在 HttpOnly＋SameSite=Strict cookie，伺服器只存雜湊
- 所有會改資料的請求都要 CSRF 標頭；登入、下單、留言都有限流（登入後依帳號算，教室共用 IP 不會互相卡）
- 前端完全不用 innerHTML；CSP 只准自己網站的程式；不准被別的網站嵌入
- 上傳只收 JPG／PNG／GIF／WebP／MP4／WebM（合約可傳 PDF），看檔頭不看副檔名，檔名隨機
- 匯出 CSV 防公式注入；前台贊助人名單只顯示遮罩後的名字

## 放上網路（給 RD、新同事直接用網址開）
用 [Render](https://render.com) 免費主機，repo 裡的 `render.yaml` 已經寫好設定：
1. 登入 Render → New → Web Service → Public Git Repository，貼 `https://github.com/hatoaikirk-maker/fundraising-practice`
2. Start Command：`node server.js`；環境變數：`HOST=0.0.0.0`、`SECURE_COOKIE=1`、`TRUST_PROXY=1`
3. 以後推新版到 GitHub，到 Render 按 Manual Deploy（或打開 Auto-Deploy）

注意：
- 免費方案 15 分鐘沒人用會休眠，第一次開要等 30～60 秒。
- 主機重開，練習資料會回到範例資料（本來就是練習用）。
- 練習帳號密碼是公開的：`admin@demo.local`、`pm@demo.local` 不能被降權、停權，所有 `@demo.local` 帳號都不能改密碼，免得有人把大家鎖在外面；資料被亂改就請 admin 按「重置練習資料」。
- 全站上傳上限 1GB。
