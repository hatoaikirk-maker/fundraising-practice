# 人生地圖募資

麥睿資訊股份有限公司經營的宮廟募資平台：前台（信眾贊助）、提案者後台、平台管理後台。

線上版：https://fundraising-practice.onrender.com

## 怎麼開

不用裝任何套件，只要 [Node.js](https://nodejs.org/) 20 以上。

- **Windows**：雙擊 `啟動募資平台.bat`，資料存在 `data\site`，會自動打開 http://localhost:3000
- **其他**：`node server.js`

| 環境變數 | 預設 | 說明 |
|---|---|---|
| `PORT` | 3000 | 埠號 |
| `HOST` | 127.0.0.1 | 只有這台電腦連得到；放主機上設 0.0.0.0 |
| `DATA_DIR` | ./data | 資料放哪（不會上傳到 repo） |
| `ADMIN_EMAIL` | admin@lifemap.local | 第一次建立資料時的管理員帳號 |
| `ADMIN_PASSWORD` | （不設） | 管理員密碼。不設的話第一次啟動會產生一組，**只印在啟動畫面一次**，登入後請到「帳號設定」改掉 |
| `SECURE_COOKIE` | 不設 | 走 https 時設 1 |
| `TRUST_PROXY` | 不設 | 放在 Render 這類主機的代理伺服器後面時設 1 |
| `DEMO` | 不設 | 設 1＝測試模式（測試帳號、測試計畫、測試金流、時鐘快轉），只給自動測試用 |

## 計畫

目前上架的是我們在嘖嘖上的 4 個計畫（文案、圖片、GIF、Vimeo 影片、回饋方案、回饋調查、常見問答）：

| 網址 | 計畫 | 類型 |
|---|---|---|
| `/p/moga` | 茅港尾天后宮・光明燈牆 | 群眾集資（首頁主打） |
| `/p/sihu` | 四湖參天宮・光明燈柱 | 群眾集資（首頁主打） |
| `/p/hsu` | 許厝福興宮・廟體修復 | 訂閱式 |
| `/p/pray` | 八間廟・把你的願望放到神明面前 | 訂閱式 |

- 計畫掛在「人生地圖」帳號底下（這個帳號沒有密碼、不能登入），由平台人員在後台管理。
- 人數、累計金額、各回饋已認領數跟嘖嘖公開頁面一樣；贊助人名單是虛構的名字，沒有任何真實贊助人資料。
- 圖片用嘖嘖的公開圖片網址。內容在 `lib/zeczec_projects.json`；要重新搬：`node tools/convert_zeczec.mjs 匯出檔路徑`。

## 付款

**線上付款尚未開放。** 信眾可以選方案、填資料、送出訂單，訂單會「保留」但不會扣款；付款 API 一律拒絕，畫面寫「線上付款尚未開放，不會扣款」。串好真的金流前不要拿掉這個保護。

## 平台人員

| 角色 | 能做什麼 |
|---|---|
| 管理員 | 全部功能；另外可以新增／管理人員、撥款結算、平台設定、寄信紀錄、操作紀錄 |
| 一般人員 | 提案審核、計畫管理、訂單、退款、檢舉、留言、首頁公告 |

管理員在「平台管理後台 → 人員與會員」新增人員，系統產生臨時密碼（只顯示一次，伺服器只存雜湊），交給本人後請他自己改。

## 功能

- **前台**：首頁（主打、熱門、群眾集資、訂閱專案、計畫動態、分類）、探索（類型、分類、狀態、排序、搜尋）、計畫頁（專案內容、計畫更新、留言、常見問答、贊助人、追蹤、分享、聯繫提案人、檢舉、隱藏選項密碼、推薦連結 `?r=`）、結帳（數量、加購、加碼、折扣碼、運費、宅配／超商、回饋調查、備註、分期、發票）、贊助紀錄、追蹤、個人頁、帳號設定、團隊、站內訊息、通知信箱。
- **提案者後台（16 頁）**：控制中心、修改計畫、常見問答、計畫回饋（圖片可放 GIF 或影片）、回饋排序、折扣碼、推薦連結、EDM 再行銷、計畫更新、數據分析、贊助名單下載、訂單總覽、退款申請、留言管理、商業檔案、金流帳號申請。
- **平台管理後台**：總覽、提案審核（五階段）、計畫管理、訂單、退款、檢舉、留言、首頁公告、人員與會員、撥款結算、平台設定、寄信紀錄、操作紀錄。

## 資安

- 不用任何外部套件；所有輸入在伺服器清洗、限長度；所有權限在伺服器判斷
- 密碼 scrypt 加鹽雜湊；session 只存在 HttpOnly＋SameSite=Strict cookie，伺服器只存雜湊
- 會改資料的請求都要 CSRF 標頭；登入、下單、留言、新增人員都有限流
- 前端不用 innerHTML；CSP 只准自己網站的程式；不准被別的網站嵌入
- 上傳只收 JPG／PNG／GIF／WebP／MP4／WebM（合約可傳 PDF），看檔頭不看副檔名；全站上限 1GB
- 匯出 CSV 防公式注入；前台贊助人名單只顯示遮罩後的名字

## 放上網路（Render）

1. Render → New → Web Service → 選這個 GitHub repo
2. Start Command：`node server.js`；環境變數：`HOST=0.0.0.0`、`SECURE_COOKIE=1`、`TRUST_PROXY=1`、`ADMIN_EMAIL`、`ADMIN_PASSWORD`（密碼自己在 Render 輸入，不要寫進 repo）
3. 推新版到 GitHub 後，到 Render 按 Manual Deploy

**注意：Render 免費方案沒有永久硬碟，主機重開（含每次部署）資料會回到初始狀態**，信眾註冊的帳號、保留的訂單都會不見。真的對外收單前，要改用付費方案加 Disk，或改接資料庫。
