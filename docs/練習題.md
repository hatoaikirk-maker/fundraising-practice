# 新同事練習題

每一題都標了要用哪個帳號登入（密碼都是 `Demo1234`）。做完一輪，請 admin 到「模擬時鐘與重置」按重置，下一位再從頭練。

## 第一關：當一次贊助人（backer1@demo.local）
1. 在首頁找到「光明燈牆」計畫，看完專案內容、常見問答、計畫更新。哪一則更新你看不到？為什麼？
2. 用推薦連結進計畫頁（到提案者後台複製一條），贊助「隨喜功德」2 份，加購平安小卡，加碼 100 元，用折扣碼 `LIGHT100`，超商取貨。
3. 付款時故意輸入卡號末四碼 `0002`，看付款失敗長怎樣；再用 `4242` 付成功。
4. 到「我的贊助紀錄」修改祈福姓名；再下一張 ATM 訂單，不要付款。
5. 輸入隱藏選項密碼 `VIP2027`，看看多出哪個方案。
6. 留一則留言、追蹤這個計畫、傳站內訊息給提案人。

## 第二關：當提案人（creator@demo.local）
1. 控制中心：說出「審核五階段」各是什麼、目前卡在哪一關。
2. 計畫回饋：新增一個「限量 50 份、可以分 3 期、不開放 ATM、要填尺寸（S／M／L）」的回饋，圖片放一張 GIF 或一段影片。
3. 建一個折扣碼、一條推薦連結；設定 EDM 再行銷並開啟每日自動寄送。
4. 發一則「只有大功德主才看得到」的計畫更新，寄信通知。
5. 到訂單總覽用收件人姓名查訂單；下載贊助人列表和出貨列表；把三張訂單標記出貨。
6. 回覆留言；處理退款申請總覽裡的申請。
7. 到「團隊設定」邀請 backer4 當客服，換 backer4 登入，看客服能做什麼、不能做什麼。

## 第三關：從零提一個案（backer5@demo.local ＋ admin@demo.local）
1. backer5「提案」→ 群眾集資，填完修改計畫、新增回饋、商業檔案（用範例資料）、金流帳號申請，送審。
2. 換 admin 到「提案審核」：先退回一次初審（寫原因），讓 backer5 看到退回原因、修改後再送。
3. 依序通過五個階段，最後排定上線時間。
4. admin 到「模擬時鐘」快轉 1 天，確認計畫上線；backer1 去贊助。
5. 快轉到募資結束：達標的話看「撥款結算」的試算（平台 5.5％＋金流 2.5％）、標記撥款；沒達標的話看訂單是不是自動退款。

## 第四關：平台方（admin@demo.local ／ pm@demo.local）
1. 處理「檢舉處理」裡的檢舉，決定要不要隱藏留言。
2. 把一個計畫設為首頁主打、編輯精選；把一個計畫下架再恢復。
3. 快轉 30 天，看訂閱式計畫有沒有自動扣下一期、撥款排在次月 15 日。
4. 改平台設定的手續費，再看撥款試算有什麼變化（記得改回來）。
5. 到「寄信紀錄」「操作紀錄」找剛剛每一個動作留下的紀錄。
